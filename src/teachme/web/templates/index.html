How it works

1 · Research. An agent builds a brief: the core tension, the step-by-step logic, real numbers, common misconceptions.
2 · Direct. A director turns the brief into scenes with narration beats and a precise visual plan.
3 · Animate. An animator writes Manim code — the same engine 3Blue1Brown built — timed to the narration.
4 · Critique. A vision critic inspects rendered frames for overlaps, cutoffs, wrong math, and dead time, then sends fixes back. Then everything gets narrated and assembled.

Every slot is pluggable: LLM backends, renderers, voices. Read the code and run it locally →
